# Product Metrics

## North Star
Weekly Meaningful Opportunity Actions

Meaningful actions:
- Save
- Application click
- Mark applied / registered

## Core Funnel
Opportunity Impression
- Opportunity Open
- Opportunity Save
- Application Click
- Marked Applied

## Supporting Metrics
- Onboarding completion
- Time to first meaningful action
- Opportunity open rate
- Save rate
- Application CTR
- D7 retention
- Recommendation engagement by rank
