# Experiment Backlog

## Recommendation Transparency

### Hypothesis
Showing why an opportunity was recommended will increase user engagement.

### Control
Opportunity card without match explanation.

### Treatment
Opportunity card with:
- Match score
- "Why this matches you"

### Primary Metric
Opportunity open rate

### Secondary Metrics
- Save rate
- Application CTR

### Guardrail
Dismissal rate

### Unit of Randomization
User
